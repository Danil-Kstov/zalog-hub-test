# Zalog Hub

Небольшое приложение для ведения задач на React, TypeScript и Tailwind CSS. Можно добавить задачу с названием и описанием, отметить её выполненной и отфильтровать список: все, активные или завершённые. Задачи сохраняются в `localStorage` браузера.

## Запуск

Нужны npm и Node.js версии 20.19+ в ветке 20 либо версии 22.12+.

В терминале из папки проекта выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173/`).

## Проверка

```bash
npm run lint
npm run build
```

## Затраченное время

50 минут.
